Sistema de gestión de tareas para estudios contables

Manual de Usuario · Versión 1.0 · Junio 2026

📖 ¿Qué es TaskFlow Pro?

Visión general del sistema

TaskFlow Pro es un sistema de gestión de tareas diseñado específicamente para estudios contables. Permite controlar en tiempo real el trabajo de cada operador, que supervisores asignen tareas con plazos y prioridades, y que los dueños accedan a métricas completas del estudio.

💡El sistema funciona en dos superficies que se sincronizan automáticamente: el browser (aplicación web accesible desde cualquier computadora) y el widget desktop (aplicación instalada en Windows que permite control rápido sin abrir el browser).

Componentes del sistema

Capacidades principales

  • ⏱️ Control de tiempo real — cada tarea registra cuándo se inició, cuándo se pausó, y el tiempo neto trabajado
  • 📋 Asignación de tareas — supervisores crean y asignan tareas con fecha, prioridad y SLA
  • 🔀 Tareas complejas — flujos de trabajo multi-etapa con validaciones entre pasos
  • 📅 Herencia automática — tareas incompletas al cierre del día pasan automáticamente al próximo día hábil
  • 📊 Métricas y reportes — tiempos por operador, por cliente, por rubro; exportables a CSV
  • 🏢 Multi-empresa — un mismo usuario puede pertenecer a múltiples estudios

👥 Roles y Permisos

Qué puede hacer cada tipo de usuario

TaskFlow Pro tiene cuatro roles. Cada usuario puede tener uno o más roles asignados. Los permisos son acumulativos: un supervisor tiene todo lo del operador, más lo suyo propio.

🔵 Operador
  • Ver sus propias tareas del día
  • Iniciar / pausar / reanudar / completar tareas asignadas
  • Agregar comentarios a sus tareas
  • Ver su historial personal
  • Usar el widget desktop
🟡 Supervisor
  • Todo lo del operador
  • Crear y asignar tareas a operadores
  • Ver tareas de todo el equipo
  • Validar etapas de tareas complejas
  • Ver la Agenda completa del equipo
  • Acceder al historial de todos
  • Crear rubros y catálogo de tareas
🟢 Dueño
  • Todo lo del supervisor
  • Reportes y métricas completos
  • Registro de Trabajo (consulta mensual)
  • Gestión de usuarios y empresas
  • Log de auditoría
  • Gestión de clientes
🟣 Administrador
  • Todo lo del dueño
  • Gestión técnica de empresas
  • Configuración de parámetros del sistema
  • Acceso a todas las empresas

Cómo acceder al sistema

TaskFlow Pro usa Google OAuth 2.0 para autenticar usuarios. No hay nombre de usuario ni contraseña propia: se inicia sesión con la cuenta de Google que fue habilitada por el administrador del estudio.

⚠️Solo los usuarios cuyo email fue registrado previamente en el sistema pueden ingresar. Si el login con Google tiene éxito pero aparece un error, contactá al administrador para que habilite tu cuenta.

TaskFlow Pro soporta que un mismo usuario trabaje en múltiples estudios. Cada sesión tiene una empresa activa que define qué datos son visibles. Para cambiar de empresa, usá el selector en la barra superior.

📅 Agenda

Vista mensual de tareas y asignación masiva

La Agenda muestra una vista de calendario mensual con todas las tareas planificadas. Los supervisores pueden usarla para asignar múltiples tareas de una vez desde el panel de sugerencias.

Componentes de la Agenda

  • Calendario mensual — cada día muestra puntos de colores que representan tareas (verde = completada, azul = pendiente, rojo = vencida)
  • Panel de detalle del día — al hacer clic en un día, se ven todas las tareas de esa fecha con sus controles
  • Panel de sugerencias (supervisores) — permite seleccionar varias tareas del catálogo y confirmarlas masivamente
  • Filtro por operador (supervisores) — para ver la agenda de un operador específico o de todo el equipo

Cambio de prioridad inline

Los supervisores pueden cambiar la prioridad de una tarea pendiente o pausada directamente desde la tarjeta en la Agenda, sin necesidad de abrirla. Solo las tareas en estado pendiente o pausada permiten este cambio.

✅Tip de asignación masiva: En el panel de sugerencias de la Agenda, podés seleccionar múltiples tareas del catálogo con los checkboxes y confirmarlas todas de una vez. Esto es útil al inicio del mes para cargar las tareas recurrentes de todos los clientes.

Herencia de tareas

Todas las noches a las 23:30 hs (días hábiles), el sistema copia automáticamente las tareas incompletas (pendiente, pausada, en curso) al próximo día hábil. La tarea heredada aparece con una etiqueta ↩ heredada en el Dashboard y la Agenda.

📋Las tareas vencidas y completadas no se heredan. Una tarea vencida puede igualmente completarse en días posteriores; en ese caso quedará marcada con el flag "fue vencida" en el historial para referencia futura.

SLA y vencimientos

Al crear una tarea, el supervisor puede definir una fecha de vencimiento y/o un SLA en horas. Cuando el plazo expira sin que la tarea esté completada, el estado pasa automáticamente a vencida.

🔀 Tareas Complejas

Flujos de trabajo multi-etapa con validaciones

Una tarea compleja es un flujo de trabajo compuesto por múltiples pasos (etapas) que deben ejecutarse en secuencia. Cada etapa puede requerir validación del supervisor antes de que la siguiente quede disponible.

Acceder a tareas complejas

El módulo Tareas Complejas (menú lateral 🔀) muestra todas las ejecuciones activas de tareas complejas. Desde ahí, supervisores y operadores pueden ver el estado de cada etapa, el timeline de validaciones, y el historial de rechazos.

⚠️Un operador no puede validar sus propias etapas. La validación siempre debe hacerla un supervisor con un usuario distinto al que ejecutó la etapa.

Reasignación de etapa

Si una etapa necesita cambiar de responsable, el supervisor puede reasignarla desde el detalle de la tarea compleja. Solo etapas en estado pendiente o bloqueada admiten reasignación.

🔍 Seguimiento

Historial de tareas y log de auditoría

La sección Seguimiento permite consultar el historial de tareas en un rango de fechas con múltiples filtros. Incluye tareas simples y complejas, con visibilidad de qué tareas alguna vez se vencieron.

Historial de tareas

Ingresá una fecha de inicio y una de fin, aplicá los filtros que necesitás, y presioná Buscar. Los filtros disponibles son:

  • Rango de fechas — obligatorio para buscar
  • Operador (supervisores y dueños) — filtrar por un operador específico o ver todos
  • Cliente — ver solo tareas de un cliente
  • Estado — pendiente, en curso, pausada, completada, vencida
  • Prioridad — urgente, alta, media, baja

Indicadores especiales en el historial

IndicadorSignificado
↩ heredadaLa tarea fue heredada de un día anterior porque no se completó a tiempo
⚠ fue vencida (naranja)La tarea estuvo en estado vencida en algún momento, aunque hoy esté completada
🔀 complejaEs una tarea compleja expandible para ver sus etapas

Tareas complejas en el historial

Las tareas complejas aparecen con un botón ▶ que permite expandirlas para ver cada etapa. El estado y tiempo de la tarea compleja se calcula como la suma de sus etapas. Si alguna etapa tuvo el SLA vencido, la tarea compleja también muestra el indicador.

✅Usá el botón ⊕ Expandir todas para ver las etapas de todas las tareas complejas del resultado de una sola vez. Útil para revisiones de período.

Exportar a CSV

Cuando hay resultados, el botón ⬇ CSV descarga el historial como archivo de planilla. El CSV incluye las columnas: fecha, tarea, tipo (simple/compleja), operador, cliente, estado, fue_vencida, prioridad y tiempo en minutos.

Log de auditoría

Los usuarios con rol dueño o administrador tienen acceso a una pestaña adicional: el Log de auditoría. Registra todos los cambios del sistema (INSERT, UPDATE, DELETE) con timestamp, usuario que realizó la acción, campo modificado y valores anterior/nuevo.

📒 Registro de Trabajo

Consulta mensual exportable de lo ejecutado

El Registro de Trabajo es el equivalente digital de la planilla de control mensual. Permite consultar todo lo ejecutado en un mes para determinados clientes o tipos de tarea, con exportación a CSV.

Navegación por mes

Usá los botones ‹ y › para navegar entre meses. No hay rangos de fechas manuales: cada consulta cubre un mes calendario completo.

Dos modos de visualización

📁 Por cliente

Agrupa todas las tareas bajo el nombre del cliente. Dentro de cada cliente, una fila por tarea. Las tareas complejas son expandibles para ver sus etapas.

📋 Por tarea

Agrupa por tipo de tarea del catálogo. La cabecera de la tarea aparece una sola vez; debajo, una fila por cada cliente donde se realizó esa tarea. Para tareas complejas, los pasos aparecen como columnas con fecha de cumplimiento y tiempo.

💡El modo Por tarea es especialmente útil cuando la misma tarea recurrente se realiza para muchos clientes (por ejemplo, liquidación de sueldos): la cabecera de columnas se muestra una vez y los datos de cada cliente debajo, igual que una planilla tradicional.

Filtros disponibles

  • Clientes — multi-selección: elegí uno o varios clientes específicos
  • Rubro — filtra el catálogo de tareas por área (impuestos, laboral, etc.)
  • Tareas del catálogo — multi-selección filtrada por el rubro elegido

Opciones visuales

  • ☑ Mostrar si fue vencida — agrega una columna o indicador visual para tareas que alguna vez estuvieron vencidas
  • ☐ Mostrar SLA de pasos — en tareas complejas, muestra la fecha SLA de cada paso además de la fecha real de cumplimiento

Exportar

Cada modo tiene su propio botón ⬇ Exportar CSV. El archivo generado tiene una columna por cada dato visible en pantalla. Para tareas complejas en modo "Por tarea", cada paso es una columna con formato fecha · tiempo.

👥 Clientes

Gestión del listado de clientes del estudio

La sección Clientes mantiene el directorio de clientes del estudio. Los clientes se asocian a las tareas para poder agrupar el trabajo por cliente en reportes y el Registro de Trabajo.

Datos de un cliente

  • Razón social
  • CUIT (validado con algoritmo AFIP módulo 11)
  • Email, teléfono, dirección, localidad, provincia
  • Responsable interno del estudio
  • Notas libres
  • Servicios contratados (con fechas de vigencia)

Permisos

Solo los usuarios con rol supervisor, dueño o administrador pueden crear, editar, activar o desactivar clientes. Los operadores tienen acceso de solo lectura.

Servicios del cliente

Desde el detalle de un cliente, se pueden gestionar los servicios contratados. Cada servicio tiene una fecha de inicio y una fecha de baja opcional. Un servicio está vigente si está activo y no tiene fecha de baja o la fecha de baja es futura.

💡Los servicios contratados son usados en el Registro de Trabajo para la vista "Por cliente", mostrando qué servicios tiene activos cada empresa.

⚙️ Gestión Administrativa

Configuración del sistema — solo dueños y administradores

La sección Administración solo es visible para usuarios con rol dueño o administrador. Contiene todos los parámetros de configuración del sistema.

Gestión de Usuarios

Desde aquí se crean y gestionan los usuarios del sistema.

  • Crear usuario: ingresá nombre, apellido, email de Google y asigná perfiles (roles)
  • Editar perfiles: podés cambiar los roles de un usuario en cualquier momento
  • Activar / desactivar: un usuario desactivado no puede iniciar sesión
⚠️El email debe ser exactamente el email de la cuenta de Google que usará la persona para ingresar. Si hay una diferencia de mayúsculas o un error, el login fallará.

Gestión de Empresas (multi-empresa)

Permite crear nuevas empresas y asignar usuarios a cada una.

  • Crear empresa: nombre, zona horaria, color de identificación, email de notificaciones
  • Asignar usuarios: desde el panel de cada empresa, usar el dropdown para agregar un usuario. Los usuarios pueden pertenecer a múltiples empresas
  • Quitar usuarios: el botón ✕ junto al usuario lo desvincula de esa empresa

Catálogo de Tareas

El catálogo define las plantillas reutilizables de tareas. Cada entrada tiene:

  • Código único (ej: LIQ-001)
  • Nombre y descripción
  • Rubro de categorización
  • Duración estimada y SLA default
  • Prioridad default
  • Flag de tarea compleja
  • Configuración de email automático al completar (asunto, cuerpo, destinatario)

Rubros

Los rubros organizan el catálogo en categorías temáticas (ej: Impuestos, Laboral, Societario). Cada rubro tiene un color e ícono para identificación visual en los reportes y el Registro de Trabajo.

Feriados

Define los días no hábiles para el estudio. El sistema usa esta lista para la herencia automática de tareas (saltea feriados al calcular el próximo día hábil).

  • Crear feriado: fecha, nombre y tipo (nacional / provincial / especial)
  • Duplicar año: copia los feriados de un año a otro (útil al inicio de cada año)

Mi Empresa

Configuración general de la empresa activa: logo, SMTP para envío de emails, horarios de trabajo y configuración regional.

🔗 Browser + Widget — Convivencia

Cómo se sincronizan las dos superficies

El browser y el widget son dos vistas del mismo sistema. Comparten el estado de las tareas en tiempo real. Cualquier acción que hagas en uno se refleja en el otro al refrescar.

Cómo funciona la sincronización del token

  1. Al hacer login en el browser, el sistema genera un token JWT
  2. El browser envía ese token al puerto local 9876 donde el widget escucha
  3. El widget almacena el token y lo usa para comunicarse con el servidor
  4. Cuando el usuario cambia de empresa en el browser, se emite un nuevo token que se reenvía automáticamente al widget

Componente individual de una tarea compleja. Tiene su propio estado, SLA y operador asignado.
Herencia de tarea
Proceso automático que corre a las 23:30 hs en días hábiles. Copia todas las tareas incompletas al siguiente día hábil, marcándolas como "heredadas".
SLA (Service Level Agreement)
Plazo máximo (en horas o con fecha límite) para completar una tarea o etapa. Si el plazo vence sin finalizar, el estado cambia automáticamente a "vencida".
Fue vencida
Indicador que marca que una tarea o etapa pasó por el estado "vencida" en algún momento, aunque hoy esté completada. Persiste en el historial para análisis de SLA.
Token JWT
Credencial de sesión encriptada que identifica al usuario y su empresa activa. Se genera al hacer login y tiene una duración limitada. El browser y el widget comparten el mismo token.
Catálogo de tareas
Biblioteca de plantillas reutilizables definidas por el administrador. Al crear una tarea desde el catálogo, se heredan nombre, duración estimada, SLA, prioridad y configuración de email.
Rubro
Categoría temática del catálogo de tareas (ej: Impuestos, Laboral, Societario). Se usa para filtrar tareas en el Registro de Trabajo y en reportes por rubro.
Multi-empresa
Capacidad del sistema de alojar múltiples estudios contables. Un usuario puede pertenecer a varios estudios y cambiar entre ellos desde el selector en la barra superior.
Validación pendiente
Estado de una etapa de tarea compleja que fue completada por el operador y está esperando aprobación del supervisor. El supervisor puede aprobar (pasa a completada) o rechazar (vuelve a pendiente).
Tiempo trabajado neto
Tiempo real de trabajo efectivo. Se calcula como el tiempo total transcurrido desde el inicio hasta el fin, menos los tiempos de pausa.
